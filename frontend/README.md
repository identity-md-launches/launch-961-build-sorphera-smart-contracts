# Contract integration artifacts (no website)

Mainnet preparation; undeployed addresses stay null. ABIs are regenerated by `python3 tools/export.py`. `configuration.json` lists exact status values; terminal states are **only Won/Rolled/Cancelled**, never an ordinal `>= Won` comparison because tie states were appended. Older integrations must adopt the refreshed Round tuple and RequestBinding ABI.

For animations, index `DrawRequested` → `RandomnessStored` → `Result` for the balls. `Result` with NFT matches >1 and winningTicket 0 is provisional: index `TieBreakRequired` → `TieBreakRequested` → `TieBreakRandomnessStored` → `TieBreakResult` separately. The final event selects one ticket for all inventory. One match uses Result's winningTicket directly; zero matches use Rollover. Never animate a winner from draw randomness while tie fulfillment is pending. Replay events by chain + lottery + game + round + request ID; FWA requests are a separate namespace.

See [operations](../docs/OPERATIONS.md), [network inputs](../deployments/config.schema.json), [mainnet evidence](../docs/MAINNET.md). Company builder `BuilderRewardClaimed`/`RewardQueued` events come from the router; purchaser tokens and NFT custody/delivery events come from the originating round vault. Helper queueing is not delivery: wait for the real helper's next-block `Claimed` event.

The current continuation preserves all `Status` numeric values and the `Round`/`RandomConfig` tuples. New `VRFReserveConfigured` plus `roundMinimumVRFBalance(game,round)` expose the frozen subscription floor; future floor edits do not change sold rounds. Vault `CancellationReviewed(cursor,requests)` and `cancellationCursor()` expose bounded pre-cancellation custody review. A successful `requestDraw` transaction may remain `Closed` while this review advances: wait for `DrawRequested` or `Cancelled`, never infer a request solely from transaction success.

The ABI/status artifacts are ready for website implementation against this source version, subject to its explicit oracle-lockup/shared-NFT policies. Deployment addresses remain null, so live website activation is not ready. Show `Requested`/`TieBreakRequested` as awaiting the original oracle indefinitely; do not offer timeout refunds or promise a redraw. Keep company builder revenue separate from purchaser rewards/prizes/refunds.
